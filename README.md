# 🐰 Astrobunny

¡Bienvenido al repositorio oficial de **Astrobunny**! Este es un proyecto de un videojuego desarrollado utilizando [GDevelop 5](https://gdevelop.io/).

## 🚀 Cómo Empezar

Para poder probar, jugar o editar el proyecto en tu ordenador, sigue estos sencillos pasos:

1. **Clona este repositorio** en un directorio que esté completamente vacío. Puedes hacerlo usando la terminal con el siguiente comando:
   
   ```bash
   git clone https://github.com/alexheads1/Astrobunny-.git
   ```
   
3. **Abre GDevelop 5** y presiona `Ctrl + O` (o alternativamente ve a **Archivo > Abrir**).
   
5. Dirígete al directorio donde has clonado el proyecto, y selecciona el archivo **"Pantalla de inicio.json"**.
